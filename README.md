# pythree1.0
## 大家好，我开发了一个项目是一个语言叫**pythree**，需要Python环境。
### 不知道大家有没有对Python密密麻麻的符号括号逼疯，特别是新手小白，经常报语法错误。
### 所以我开发了pythree，整个语言只有**字母**和**下划线**，没有其它多余符号。
### 每一个语法都是三行，请遵循，否则代码将无法运行。
### 1.0版本仅支持print和input。
## 语法规则
1. 三行为一个模块
2. 第一行写**关键字**就是print或input
3. print第二行写**v**或**string**，分别表示第三行是打印**变量**还是**字符串**
4. input第二行写**变量名**，任何字母都可以，表示回答保存到那个变量
5. print第三行写**变量名**> （第二行写v的情况下）,写**字符串**> （第二行写string的情况下）
6. input第三行写**提示语**
## 创建方法
